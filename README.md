# 窝知项目资料站

由杜亮宽维护的项目介绍与资料索引，独立于冻结的比赛仓库、原型应用和设备遥控台。正文使用静态HTML，项目与个人分工、演示与验证范围分开说明。

```sh
node build.mjs
node verify.mjs
```

Vercel输出目录为dist，采用cleanUrls。页面与llms资料由content.json统一生成。无需第三方npm依赖，字体自托管并包含原始OFL许可证。

assets/nest-study.svg为本站原创概念结构示意，非实物照片或制造工程图。未复制原型仓库中注明第三方权利的商品、社区图片。产品事实主要参考 https://github.com/chimeraHHH/aidol-s2 的公开说明；本人分工与维护关系明确标示。

新增资料应依据真实记录，不将Mock、现场展示或传输联通扩写成测量精度、量产或医学验证。不要修改或移动原项目final标签。
