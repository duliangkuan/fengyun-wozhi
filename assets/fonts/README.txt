Self-hosted web font subsets

Families: IBM Plex Sans, JetBrains Mono, Noto Sans SC.
Source: Google Fonts assets obtained by the existing Next.js font build on 2026-10-29.
These are the original WOFF2 subsets, served locally so production builds and readers do not depend on remote font downloads.
See the accompanying OFL-ibmplexsans.txt, OFL-jetbrainsmono.txt and OFL-notosanssc.txt for copyright and licence terms.
Canonical licence sources: https://github.com/google/fonts/tree/main/ofl/ibmplexsans
